# Architecture Decision Records

This directory was reconstructed on 2026-08-13 from repo history — commit
history, issues/PRs, `CLAUDE.md`, and fleet incident/session records — as
part of a fleet-wide ADR reconstruction effort. These entries were written
after the fact, not at decision time; each one is dated with the original
decision date where the evidence supports it, and the `Status` line marks
the reconstruction date separately so the provenance stays visible. Where
evidence didn't check out or wasn't found, that's stated in the entry
rather than assumed. Each entry's **Alternatives** section separates what
was actually recorded at decision time from options assessed only in
retrospect (explicitly labeled) — the retrospective options were not
weighed historically and are not presented as if they were.
